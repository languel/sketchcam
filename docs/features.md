# Feature reference

See [Getting started](getting-started.md) for installation and a first session.

- **Sources**: any camera, or a looping movie file / http(s) stream with 0–2x playback speed (0 = pause) for deterministic testing; freeze-frame on any source (⌘F); export the current published frame as PNG with alpha (⌘E).
- **Audio and text**: Microphone and Audio File sources share PCM, loudness, pitch and spectrum features. Text layers consume scripts or on-device WhisperKit speech, with subtitle cues, N words, building/type-on captions and fading words. Customize fonts/layout, save Text presets, choose timed fades or hold-until-replaced cards, and smooth voice-driven scaling. Optional filler filtering and hidden recognition annotations keep captions clean; named annotation/voice events can advance scripts, while custom voice phrases invoke registered actions or Text looks. Audio and model loading require explicit starts. See [audio and text](audio-text-streams.md) for setup, manual checks and limits.
- **Effects**: order-sensitive per-layer chains with Threshold, Outline, Blur, Invert, Mirror, Person Key, Optical Flow visualization, and Levels. Effects operate on the output of the preceding effect and can also feed Ink as a processed material/motion source.
- **Layers**: camera, movie, solid, paper, drawing, ink, acrylic, and web sources with opacity, blend modes, masks, routing, and reusable effect chains. Each workspace frame can independently participate in the program output and the secondary **Presentation** output. A fresh state starts with Camera → Threshold only. Published BGRA frames carry real alpha for downstream compositing.
- **Person keying**: Vision person segmentation (fast/balanced/accurate) masks the layer stack to the person — Cutout or flat-color Silhouette mode, invertible (the outline always stays on the subject).
- **Marks** (raw landmark data): Apple Vision backend (synthetic source for tuning), tracked as fine-grained regions — face split into Jaw / Nose / Mouth / L+R Brow / L+R Eye, body into Head / Torso / L+R Arm / L+R Leg, plus Hands and a silhouette Contour — each independently toggleable with its own color + size. Rendered as dots and/or a MediaPipe-style stick figure (eye shapes, articulated fingers, body skeleton); stable IDs with adjustable color-matched labels (hands use MediaPipe 0–20 indices), adjustable detection rate. Jitter-stable: canonical joint ordering, chirality-locked hands, identity-keyed smoothing with dropout carry-over. The **Contour** follows the silhouette boundary (Moore tracing) with an adjustable Detail (granularity) so it hugs concavities.
- **Drawing** (art from the landmark data): modular algorithms that each toggle independently and **layer** on the canvas, with their own style and stroke controls. Add independent **Drawing passes** (Portrait, Yarn, Wrap, or Line walk) from Layers; each pass has its own landmark-category selection, so different regions can use different algorithms. Seeded algorithms remain deterministic so their shapes stay stable under motion.
  - **Yarn** — seeded woven tangle per feature; Weave (waviness), coil/loop Noise (linear × circular) and Winding.
  - **Wrap** — a continuous yarn-wire that winds through the *inside* of the person (Gormley-style): heavy interior sampling, proximity-ordered, with LineWalk-style Wildness/Scale and coil/winding Loops.
  - **Line walk** — "taking a line for a walk": one or more continuous lines planned through the semantic features. Continuity (one unicursal line → separate paths → fragments), Density, a Curve picker (Polyline / Spline / Hobby / Bezier), a 2-D Wildness pad (along-path × orthogonal), Scale (local↔global).
  - **Portrait** — the original landmark itineraries remain available, alongside a **Gesture** approach that traces live eye, brow, lip, nose, and jaw features, and invents a rotating scalp, neck, and shoulders around them. Abstraction, Expression, and seeded Shape variation tune likeness and character while preserving the pen route. See [portrait drawing](portrait-drawing.md).
  - All algorithms render as smooth variable-width **ribbons** (calligraphic taper/swell) with an optional glow **Halo**; an optional **GPU (Metal)** path tessellates every enabled algorithm in one pass.
  - The original merged Drawing producer remains available. It and independent Drawing passes can use live Landmarks or the shared Mouse/canvas stroke stream. Committed strokes and the active stroke are routed without consuming Ink's own live samples.
- **Motion Control**: a homunculus-style hand map selects a pointer landmark. Canvas can use an ordered custom stack of per-hand paint actions plus passive joint-distance/angle controls for Ink parameters; the simple gesture presets remain available. Computer presets move/click/drag, right-click, scroll, send a small set of shortcuts, or disarm. Computer control requires Accessibility approval and explicit arming each launch; Canvas does not. Tool sequences support held poses, finger signs, squeezes and tracked-joint tests; Gesture Cues shows recognition feedback. See [motion tools and commands](motion-tools.md).
- **Ink**: a full-canvas Metal fluid-simulation inkwash layer (velocity/pressure/vorticity with a persistent wetness gate, chromatic diffusion, fixed pigment, and Beer-Lambert display). Pen and wash have independent sizes; Option-drag sprays water without pigment or displacement; **Wet canvas** and **Motion wetness** prepare regions for routed optical flow to carry pigment. Cached procedural paper supplies both a visible substrate and absorbency/drag/resistance fields. Editable parameter fields accept exact or experimental values, and double-clicking any numeric parameter label restores its factory default. See [ink-simulation notes](../notes/ink-simulation.md) for the algorithm and control mapping.
- **Presets**: save and recall app states, plus dedicated Portrait and Text looks. Text looks retain typography, layout, timing, filtering and motion settings while preserving source connections.
- **Session recovery**: the live layer graph, processing choices, source selection, camera preference, movie bookmark/playback rate, output format, and window/output choices are saved and restored on relaunch. Rapid edits such as canvas pan/zoom coalesce their session writes. Camera access is rechecked on launch/app activation; the Camera tab requests permission when needed and reconnects the remembered device when available.
- **UI**: dockable/floating controls for Settings, Layers, Camera, Movie, Microphone, Audio File, Script, Text, Marks, Input Map, Gesture Cues, drawing algorithms, Ink, Paper, Web, Presets, Keys, Output, History, Performance and Debug, with compact one-line style rows. The Output window can show the program viewport or the independently filtered Presentation composite.
- **Performance controls**: input resolution (352/VGA/720p/native), processing resolution decoupled from output (full/720p/540p), output format, preview on/off, GPU drawing + stroke style toggles (Settings ▸ Rendering), a **Performance** panel (Control–Option–P) with pipeline FPS and per-stage timings, and an Analysis section with independent live-feature and person-matte bypasses. The GPU compositor renders effects at the selected processing resolution and upscales once for the published output; disabled effect chains are true no-ops. See [performance notes](../notes/performance-plan.md) for the audit, filter-only workflow, and measured numbers.


History provides canvas undo/redo controls and a configurable history depth. The Timeline panel is an early placeholder; editable audio/caption timelines are not implemented.
